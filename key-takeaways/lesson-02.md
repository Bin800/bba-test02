# Tổng hợp kiến thức/ghi chú buổi 2
1. Toàn bộ tên file, folder viết theo kiểu kebab-case, viết thường toàn bộ. Eg: **01-hello.js**, **folder-01**
2. Chạy file trên terminal: **"node <tên file>"**. Trường hợp nếu file nằm trong folder thì vài thêm folder vào đg dẫn. Eg: "node <tên-folder/tên-file>
3. Copy code nhanh bằng cách để dấu nháy cuối dòng code, sau đó bấm copy-paste
4. JS chấp nhận cuối mỗi dùng code có hoặc không tuy nhiên nên có vì sẽ dễ nhìn + tránh lỗi file phức tạp hơn
5. Xác định rõ biến có thay đổi hay không để sử dụng const hoặc lettel. Nên dùng const để an toàn hơn
