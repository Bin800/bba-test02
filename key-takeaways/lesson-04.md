# Tổng hợp kiến thức/ghi chú buổi 4

## 1. Array
- Array là mảng, dùng để lưu nhiều giá trị trong cùng một biến
- Có thể truy cập phần tử theo chỉ số: `arr[0]`, `arr[1]`
- `length` là độ dài của mảng
- Có thể thay đổi giá trị trong mảng
- Các thao tác cơ bản: `push()`, `pop()`, `unshift()`, `shift()`

## 2. Duyệt mảng bằng `for`
- Dùng `for` để lặp qua từng phần tử
- Thường dùng biến `i` làm chỉ số
- Chạy đến khi `i < arr.length`

## 3. Object
- Object dùng để lưu dữ liệu theo cặp key-value
- Ví dụ: `name`, `dob`, `title`
- Có thể truy cập bằng `object.key`
- Có thể thêm hoặc xóa thuộc tính
- Object lồng nhau là object nằm trong object khác

## 4. Function
- Function giúp tái sử dụng code
- Có thể nhận tham số và thực thi logic bên trong
- Dùng khi cần lặp lại một công việc giống nhau nhiều lần
- Gọi function bằng tên function và truyền tham số nếu cần

## 5. Một số phương thức array quan trọng
- `map()`: tạo mảng mới từ mảng cũ theo logic xử lý
- `filter()`: lọc các phần tử thoả điều kiện
- `find()`: tìm phần tử đầu tiên phù hợp
- `reduce()`: gom các phần tử thành một giá trị duy nhất
- `some()`: kiểm tra có ít nhất một phần tử thoả điều kiện hay không
- `every()`: kiểm tra tất cả phần tử đều thoả điều kiện hay không
